## چرا قیچی؟

هر روز کلی پیامک تبلیغاتی، قرعه‌کشی و ناخواسته به گوشی‌مان می‌رسد. هر کدام با یک اعلان و صدای جدید حواسمان را پرت می‌کند و تمرکزمان را به هم می‌زند؛ پیام‌های مهم هم لابه‌لای آن‌ها گم می‌شوند.

قیچی یک برنامهٔ پیامک کامل برای اندروید است که این پیام‌ها را با هوش مصنوعی **روی خود گوشی** تشخیص می‌دهد و بی‌سروصدا به بخش «هرزنامه» می‌برد. نه اعلانی، نه صدایی. متن پیام‌هایتان هم برای بررسی به هیچ سروری فرستاده نمی‌شود.

## ✂️ امکانات اصلی

### تشخیص هرزنامه روی گوشی
- مدل هوش مصنوعی (ML.NET) که بدون اینترنت و کاملاً روی گوشی کار می‌کند.
- هرزنامه‌ها هیچ اعلان یا صدایی ندارند و تمرکزتان را به هم نمی‌زنند.
- سه سطح حساسیت (ملایم، متعادل، سخت‌گیر) که می‌توانید دقیق‌تر هم تنظیمش کنید.
- پیام مخاطبان ذخیره‌شده هیچ‌وقت بررسی نمی‌شود؛ هر فرستندهٔ دیگری را هم می‌توانید به فهرست «مورد اعتماد» اضافه کنید.
- هرزنامه‌های قدیمی بعد از مدتی که خودتان تعیین می‌کنید خودکار پاک می‌شوند.
- مدل تشخیص از داخل برنامه به‌روز می‌شود و لازم نیست نسخهٔ جدید نصب کنید.
- خلاصهٔ روزانه: یک اعلان بی‌صدا در ساعتی که خودتان انتخاب می‌کنید، مثلاً «امروز ۱۲ هرزنامه گرفته شد». با لمسش مستقیم به بخش هرزنامه می‌روید.
- آمار هرزنامه: تعداد در بازه‌های مختلف، نمودار ۱۴ روز اخیر، میزان اطمینان، دقت تشخیص و فرستنده‌هایی که بیشترین هرزنامه را داشته‌اند.
- اگر پیامی اشتباه تشخیص داده شد، گزارشش کنید. قبل از ارسال، متن را می‌بینید و می‌توانید اطلاعات شخصی را از آن پاک کنید.

### یک برنامهٔ پیامک کامل
- پشتیبانی کامل از **چند سیم‌کارت**: نمایش سیم‌کارتی که پیام با آن رسیده، سیم‌کارت پیش‌فرض و سیم‌کارت ثابت برای هر گفتگو.
- واکنش با ایموجی به پیام‌ها، سازگار با آیفون و Google Messages.
- بایگانی گفتگوها با یک کشیدن ساده به کنار.
- جستجوی سریع با فیلتر خوانده‌نشده، ستاره‌دار، شناس، ناشناس، لینک‌ها و مکان‌ها؛ با امکان جستجوی صوتی.
- صفحهٔ پروفایل برای هر گفتگو، با لینک‌های ارسال‌شده و تنظیمات اعلان و سیم‌کارت.
- بی‌صدا کردن موقت هر گفتگو: یک ساعت، هشت ساعت، تا فردا صبح، یک هفته یا تا وقتی خودتان دوباره روشنش کنید.
- پاسخ سریع از داخل اعلان، و امکان پنهان کردن متن پیام در صفحهٔ قفل.

### ظاهر و تجربهٔ کاربری
- کاملاً **فارسی و راست‌چین**، همراه با نسخهٔ انگلیسی.
- روان و سریع، حتی با هزاران پیام.

## 🧠 مدل و دیتاست

مدل تشخیص هرزنامه در مخزن جداگانهٔ [sms-spam-dataset](https://github.com/MahdiyarGHD/sms-spam-dataset) آموزش داده می‌شود. دیتاست پیامک‌ها، کد آموزش و هر نسخهٔ مدل همان‌جا منتشر می‌شود و قیچی نسخه‌های جدید را از همان‌جا دریافت می‌کند.

گزارش‌هایی که از داخل برنامه می‌فرستید به بهتر شدن دیتاست و نسخه‌های بعدی مدل کمک می‌کنند.

## 🔒 حریم خصوصی

- تشخیص هرزنامه کاملاً روی گوشی انجام می‌شود و متن پیام‌هایتان برای این کار جایی فرستاده نمی‌شود.
- فقط وقتی خودتان پیامی را گزارش کنید متنی از گوشی خارج می‌شود؛ آن هم بعد از اینکه آن را دیدید و ویرایش کردید.
- بررسی نسخهٔ جدید برنامه و مدل فقط فایل‌های عمومی GitHub را می‌خواند.

## 📲 نصب

- **نیازمندی:** اندروید ۷ یا بالاتر.
- فایل APK را از [صفحهٔ نسخه‌ها](https://github.com/MahdiyarGHD/GheychiApp/releases/latest) دانلود و نصب کنید.
- در اولین اجرا، قیچی را برنامهٔ پیامک پیش‌فرض کنید؛ اندروید فقط به برنامهٔ پیش‌فرض اجازه می‌دهد پیامک‌ها را دریافت و مدیریت کند.
- برنامه هر روز خودش نسخهٔ جدید را بررسی می‌کند.

## 🛠️ ساخت از روی کد

پیش‌نیازها: .NET SDK 10 و workload اندروید (`dotnet workload install maui-android`).

</div>

```bash
git clone https://github.com/MahdiyarGHD/GheychiApp.git
cd GheychiApp
dotnet build src/Gheychi.App/Gheychi.App.csproj -c Release -f net10.0-android
```

<div dir="rtl">

مدل تشخیص هرزنامه داخل مخزن نیست. اولین ساخت، آخرین نسخهٔ آن را از مخزن [sms-spam-dataset](https://github.com/MahdiyarGHD/sms-spam-dataset) دانلود می‌کند.

اجرای تست‌ها:

</div>

```bash
dotnet test tests/Gheychi.Core.Tests
```
